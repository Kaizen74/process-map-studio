# Load control — Gap analysis: external best practice
Version v0.1 · run <date> · finalised <date>
Advisory evidence summary: not a legal, regulatory or audit opinion.

## 1. Facts

- [R] Second-person check of the load sheet before signing: Guidance and regulator material have a second qualified person check the load sheet before it is signed.
  - Illustrative industry guidance on load control (industry association, March 2024) https://www.iata.org/illustrative/load-control-guidance: “The load sheet shall be checked by a second qualified person before it is signed.”
  - Illustrative regulator material on mass and balance (regulator, January 2025) https://www.easa.europa.eu/illustrative/mass-and-balance: “Operators shall ensure that mass and balance documentation is checked by a second qualified person before it is signed.”
- [R] Deviation tolerances agreed in writing: Deviation tolerances are agreed with each airline in writing.
  - Illustrative regulator material on mass and balance (regulator, January 2025) https://www.easa.europa.eu/illustrative/mass-and-balance: “Deviation tolerances are agreed with each airline in writing.”
- [R] Final load sheet issued by a set time: Guidance issues the final load sheet no later than 15 minutes before departure.
  - Illustrative industry guidance on load control (industry association, March 2024) https://www.iata.org/illustrative/load-control-guidance: “The final load sheet is issued no later than 15 minutes before departure.”
- [R] Automated checks of the load sheet: Automated tools check the load sheet and flag deviations.
  - Illustrative vendor blog on automated load planning (other, June 2025) https://loadplanning-software.example.com/blog/automation: “Automated tools check the load sheet and flag deviations.”
